Every skill your AI tools have, one switch each.

Loadout is a free menu-bar app for the Mac. It lists every skill installed for Claude Code, Cursor, and OpenCode, live from disk, and turns each one on or off. It edits your global agent prompts too.

Lives in the menu bar.

What's active, in two seconds.

The backpack next to your clock is the whole app most of the day. Click it and the popover shows your most recently changed skills, a switch for each, and the count of what's on.

For real housekeeping, Open Loadout brings up the library: every skill across all four skills folders (~/.claude, ~/.cursor, ~/.config/opencode, and the shared ~/.agents), searchable, with multi-select and bulk switches. Directory watchers keep both views current, so a git pull in your skills folder shows up on its own.

How it works.

Two switch mechanisms, one prompt editor. All reversible.

Claude Code and the Agent SDK

The switch writes Claude Code's documented skillOverrides map in ~/.claude/settings.json. Claude Code watches that file, so a toggle reaches live sessions, and apps built on Anthropic's Agent SDK read the same map. The skill's folder never moves.

Four states per skill, matching the documented values: on, name only, user-invocable only, off.

architect off
~/.claude/settings.json
{
  "skillOverrides": {
    "architect": "off",
    "design-motion": "name-only"
  }
}

Cursor, the agents directory, OpenCode

These tools have no override map, so their switches shelve the folder instead. Off moves it to Loadout's shelf; on moves it back, byte-identical. Symlinked skills are never moved.

lossless shelving
off~/.cursor/skills/arena/  →  ~/Library/Application Support/Loadout/shelf/cursor/arena/onrestored to ~/.cursor/skills/arena/, byte-identical
The shelf is a plain folder. Even without Loadout, your skills are right there.

Global prompts, same window

Two global instruction files open in the same window for quick edits: CLAUDE.md for Claude Code, and AGENTS.md for OpenAI's Codex CLI. Codex is a bonus here: Loadout doesn't manage its skills, just this one file. Autosave is revision-guarded: if a file changes on disk while you type, Loadout refuses to clobber the newer copy.

system prompts
CLAUDE.md ~/.claude/CLAUDE.md
AGENTS.md ~/.codex/AGENTS.md

Careful with your files.

Every action reversible, every claim checkable in the source.

One backup, made once
Before its first write, Loadout copies your settings to ~/.claude/settings.json.loadout.bak and then leaves the backup alone.
One key owned
It patches skillOverrides and nothing else. Every other setting keeps its value, and file permissions are preserved.
Delete means Trash
Deleting a skill moves its folder to the macOS Trash, recoverable like any file. Nothing is erased in place.
Open source, tested
MIT licensed. The engine that touches your files is a separate, fully unit-tested Swift package. Read it before you trust it.
What goes over the network
Two things: an update check against GitHub Releases, and anonymous PostHog analytics under a random install id. Events carry skill folder names, never file contents.

The app says it in-place too: Turn Off hides skills, files stay on disk.
